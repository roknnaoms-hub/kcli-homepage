# 한국사이버리터러시연구원 홈페이지

홈페이지 공개 배포 전용 저장소입니다. 연구 코드, 내부 문서 및 기존 저장소 이력을 포함하지 않습니다.

HTML, CSS, JavaScript와 홈페이지에서 연결하는 이미지·안내자료로 구성됩니다.

## 운영

GitHub Pages: main 브랜치 / (root).
문의는 전화 및 이메일로 연결됩니다. 홈페이지에서 신청정보를 수집하거나 저장하지 않습니다.

교육 일정과 비용, 자격 등록 조건은 담당자 및 관련 기관의 최신 안내를 확인하십시오.

### 가비아 도메인 포워딩과 HTTPS

- `kcli.ai.kr`와 `www.kcli.ai.kr`의 고정 포워딩은 HTTP 프레임 안에 홈페이지를 띄웁니다. HTTPS LMS도 그 프레임 안에서 열면 `SameSite=Lax` 로그인 쿠키가 유지되지 않을 수 있습니다.
- 즉시 적용할 포워딩 설정: 가비아 DNS 관리툴에서 두 주소 모두 **유동 포워딩**, 연결 주소 **`https://roknnaoms-hub.github.io/kcli-homepage/`**로 설정합니다. 이동 후 주소창은 HTTPS 홈페이지 주소로 바뀝니다.
- 홈페이지의 LMS 링크는 `target="_top"`으로 열며, 프레임 접속 시 보안 홈페이지·수강생 로그인 이동 버튼을 표시합니다. 로그인 화면도 프레임·비보안 환경에서는 입력란 대신 독립 HTTPS 화면으로 이동하는 버튼을 표시합니다.
- 사용자 도메인 자체에 HTTPS를 적용하려면 포워딩 대신 GitHub Pages 사용자 도메인을 설정합니다. DNS 변경 전에 GitHub Pages에 `www.kcli.ai.kr`를 등록하고, 가비아에서 충돌하는 웹 포워딩 레코드를 해제한 뒤 `www` CNAME을 `roknnaoms-hub.github.io.`로, 루트 `@` A 레코드를 `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`으로 연결합니다. 메일용 MX·TXT 등 무관한 레코드는 보존합니다. 인증서 발급 후 **Enforce HTTPS**를 켜고 두 도메인과 LMS 로그인을 확인합니다.
- DNS 변경 전에는 `CNAME` 파일을 추가하지 않습니다. 기존 GitHub Pages 주소까지 준비되지 않은 사용자 도메인으로 이동해 접속이 끊길 수 있습니다.

## ISO 19011 온라인 강의 영상 등록

`iso-19011-classroom/lessons.json`에서 등록할 교시의 `title`과 `videoUrl`을 입력합니다. `id`는 교시 번호(1~12)입니다. 교시 제목을 비워 두면 번호만 표시되고 `videoUrl`이 비어 있으면 강의실에서 ‘영상 준비 중’으로 표시됩니다.

- 영상·학습자료는 외부 호스팅을 기본으로 합니다. 공개 승인을 받은 실제 자료만 연결하며, 승인되지 않은 자료나 가상의 URL을 등록하지 않습니다. 영상은 브라우저에서 재생 가능한 MP4·WebM 직접 HTTPS URL을 사용하고 재생·탐색을 확인합니다.
- 저장소에 영상·자료 파일을 포함하는 예외는 공개 승인과 실제 파일 확인 후에만 처리합니다. 개인정보·평가 답안·관리자 인증정보는 이 공개 저장소에 저장하지 않습니다.
- `main`에 반영한 뒤 공개 강의실에서 해당 교시의 재생과 탐색을 확인합니다. 다른 영상으로 교체할 때는 새 파일 주소를 사용해 새 브라우저 시청 기록이 시작되도록 합니다.

### 교육·평가와 공식 기록

- 12시간은 교육 인정 시간이며 영상 길이의 합계가 아닙니다. 기존 12개 영상 슬롯을 유지합니다.
- 온라인·대면 모두 12시간 인정 후 필기평가, 워크숍 교육, 워크숍 결과평가가 필수입니다.
- 온라인 전용 CBT는 별도 평가로 공통 필기평가를 대체하지 않습니다. 대면교육은 별도로 진행하며 CBT를 적용하지 않습니다.
- 실제 수강생·관리자 기록은 기존 [수강생 LMS](https://kcli-iso19011-records.roknaoms.chatgpt.site/classroom)와 [관리자 로그인](https://kcli-iso19011-records.roknaoms.chatgpt.site/admin/login)에서 관리합니다. 이 저장소는 LMS를 배포하거나 수정하지 않습니다.
- 공개 강의실은 현재 브라우저에서 실제 재생한 구간이 영상의 90% 이상이면 ‘시청 완료’로 표시합니다. 이는 공식 출석·12시간 인정·평가 합격·최종 이수 증빙이 아니며 LMS에 자동 전송되지 않습니다.
- JSON 내보내기는 기존 형식을 유지하는 참고용 기능입니다. 담당자 요청 시 지정된 비공개 경로로만 제출하며 공개 저장소에 올리지 않습니다.

## 검색 노출 관리

- 공개 페이지의 대표 주소는 `https://roknnaoms-hub.github.io/kcli-homepage/`입니다. 공개 페이지 주소가 추가되거나 변경되면 `sitemap.xml`과 각 페이지의 대표 주소를 함께 확인합니다.
- 저장소 루트의 `3bd4ce3f1a1d7b30d0acefab32a9f253.txt`는 IndexNow 요청에 사용하는 공개 확인 파일입니다. 네이버에 갱신을 알릴 때 `keyLocation`에는 `/kcli-homepage/` 아래에 배포된 이 파일의 전체 URL을 지정합니다.

## ISO 조항 이미지 갱신

`index.html`의 연수교육 표준 4~10항을 수정한 경우 SVG와 PNG를 다시 생성합니다. Node.js, Playwright Chromium과 Noto Sans CJK KR 글꼴이 필요합니다.

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node scripts/build-iso-datasheets.cjs
```

생성된 `assets/iso-datasheets/` 파일을 HTML 변경과 함께 커밋합니다. 표준 판 또는 추록 번호가 바뀌면 해당 표준의 이미지 링크 파일명도 바꿉니다.
